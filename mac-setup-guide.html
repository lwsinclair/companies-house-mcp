Prerequisites

Node.js: Check if you have it by opening Terminal and running node --version

If not installed:

• Easy way: Download from nodejs.org

• With Homebrew: brew install node (if you have Homebrew)

Installation

1. Clone and build

Open Terminal and run:

git clone https://github.com/aicayzer/companies-house-mcp.git
cd companies-house-mcp
npm install
npm run build
